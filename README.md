# 두리번 🐾 — 충남대학교 대덕캠퍼스 길안내 챗봇

자연어 키워드를 던지면 건물·호실을 알아서 해석해 약도와 길안내를 보여주는 챗봇입니다.

## VS Code에서 실행하기

### 1. 준비물

- **Node.js** 설치 (https://nodejs.org 에서 LTS 버전 다운로드)
  - 설치 확인: 터미널에서 `node -v` 입력 시 버전이 나오면 OK

### 2. 실행 순서

1. VS Code에서 이 폴더(`duribeon`)를 엽니다. (파일 → 폴더 열기)
2. 상단 메뉴 **터미널 → 새 터미널** 을 엽니다.
3. 아래 명령어를 차례로 입력합니다.

```bash
npm install
npm run dev
```

4. 잠시 후 터미널에 `Local: http://localhost:5173/` 같은 주소가 뜹니다.
   브라우저가 자동으로 열리며 챗봇이 나타납니다.
   (안 열리면 그 주소를 직접 브라우저에 입력하세요.)

### 3. 종료

터미널에서 `Ctrl + C` 를 누르면 종료됩니다.

## 사용 예시

입력창에 자유롭게 키워드를 던지면 됩니다.

- `공과대학 4호관 메카트로닉스공학과 학생회실 가고싶어`
- `정문에서 인문대 가는 길`
- `523호`
- `박진성 교수님 연구실`
- `캡스톤 제작실`
- `비 와서 실내로`

## 폴더 구조

```
duribeon/
├── index.html              # HTML 진입점
├── package.json            # 의존성 정보
├── vite.config.js          # 빌드 설정
└── src/
    ├── main.jsx            # React 렌더링 진입점
    └── CNUNavigator.jsx    # 챗봇 본체 (데이터 + 로직 + UI)
```

## 데이터 수정하기

`src/CNUNavigator.jsx` 파일 상단의 다음 부분을 수정하면 됩니다.

- `BUILDINGS` : 건물·호실 목록 (공대 4호관 호실은 안내판 기준으로 입력됨)
- `ORIGINS` : 출발 가능 지점
- `NODES` / `EDGES` : 보행로(약도 경로) 정보
- `SYNONYM` : 줄임말 사전 (예: 공대 → 공과대학)
